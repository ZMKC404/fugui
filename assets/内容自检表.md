# 内容自检表（十问体检）

> 用法：让用户对照最近的10条内容（或你帮用户逐条分析）。全部填完再看诊断结论。用户没时间填完时，只填带★的三题也能出初步诊断。

## A. 情绪层次判定（每条内容归一层）
翻出最近10条内容，逐条标记：
- L1 客观事实：在讲我的资历/成绩/产品参数
- L2 客观感受：在讲道理/干货/行业分析
- L3 主观想象：在讲"你是不是也这样/我懂你/我们一起"

| # | 内容主题一句话 | L1/L2/L3 |
|---|---|---|
| 1 | | |
| 2 | | |
| ... | | |
| 10 | | |

★ 统计：L1___条 L2___条 L3___条（大多数停在L1/L2 = 需要重写内容视角）

## B. 三种病筛查（★必答）
- 收藏/赞数和涨粉数比：收藏明显高、涨粉明显低？→ 疑似免费教材病
- 内容覆盖的topic数量 vs 你能被一句话记住的标签：topic多而标签模糊？→ 疑似百科全书病
- 最近的爆款内容，主页其余内容还在同一个"感觉"里吗？→ 不是=疑似一次性消费病

## C. 灵魂自检（★必答，凭直觉快答）
1. 用户提到我的名字，浮现的是____（形容词？还是一种感觉？）
2. "你一定要关注那个____的博主"——朋友会怎么填这个空？
3. 用户深夜刷到我，我希望他产生的感觉是____

## D. 主页3秒测试
- 冷藏3秒看自己主页：能看出我是谁/代表什么感觉吗？____
- 最新三条内容的封面上，有同一种"感觉"吗？____

## E. 反馈探针（有数据就填，没有就跳过）
- 评论区里用户用过的词，出现最多的是：____
- 用户转发我的内容时通常@谁/配什么话：____
- 私信/咨询里被问最多的问题是：____

填完后交给 Agent 出诊断：病症判定+停在哪层+1个今天就能做的动作。
