# 翻译器：把"我的表达"翻译成"用户的语言"

核心原则：**你一直在讲卖点，用户只听买点。干货让人收藏，情绪让人关注。**（【峰会·找病】）
翻译不是修辞游戏，是视角切换：从"我有什么"切到"你正经历什么"。

## 四个翻译操作

### 1. 卖点→买点（把资质翻译成共鸣）
原表【峰会·找病】（课程示例，用于学模式；给用户产出时按其行业现造，见下方造句法）：
| 卖点（IP语言） | 买点（人的语言） |
|---|---|
| 我从业10年 | 我过去10年踩过的坑，每一个都不想让你再踩一次 |
| 我带过500个学员 | 带过这么多人，每一批的问题都有几个跟你情况一模一样 |
| 我的方法论很系统 | 我把它拆成了3步，新手也能学会 |
| 我很专业 | 你这个问题一般人的解释是X，我的看法不一样 |
| 我出过书/上过央视 | 别说，让别人替你说 |

**造句法**（把模式迁移到任何行业，产出自造示例）：
1. 找到卖点里的"数字/资历"→ 换成"这段资历里用户最痛的那个瞬间"。
2. 把主语从"我"换成"你"：句子里至少出现一次用户的具体处境。
3. 资历不删，降级为故事的背景板（"那年我还在XX"）。
自造示例：家装设计师"我从业12年"→"装修踩的坑我替你踩过一遍了，光水电这块我就见过37种返工"；日语老师" JLPT满分"→"我当年也卡在听力上天天想撕书，后来发现是练反了顺序"。

机制：资质回答"凭什么信我"，买点回答"你懂不懂我"。陌生人先要后者才肯听前者。
正例：「我曾经加班到凌晨2点，就为了手动处理一份表格。后来我发现，其实3个快捷键就能搞定。我那时候怎么没人告诉我？」——先给处境，再给方案，资质藏在故事里。
反例：「Excel有3个快捷键，能帮你提升50%效率。」——正确但无主语的人生，用户收藏方法，不记得你。

### 2. 买点词倒推（从用户状态推词）
操作【AI课·观众笔记】（富贵现场作业法）：不要从产品出发想词，先问——**"用户在什么状态下会需要它？"** 把状态写成具体画面（脖子疼、凌晨睡不着、不敢辞职），状态词就是买点词。
例：卖枕头 → 用户状态：脖子疼/睡眠不足 → 内容围绕这些状态说话，而不是围绕枕头材质。
自检：这个词用户会不会原样说出口？用户不会说的词（"匠心工艺""赋能"）都不是买点词。

### 3. 私域话术→公域内容（换信任前提）
【峰会·过河】私域（已经认识你）：逻辑说服+关系信任，长文/PPT/私聊。公域（零信任、3秒决定）：情绪穿透+第一眼感觉，15秒/一张封面，0.5秒定生死。
亲子教育IP对照案例（同一人，同一专业）：
| | 私域（能成交但发不了公域） | 公域（能穿透陌生人） |
|---|---|---|
| 开头 | "我是XX教育创始人，从业15年..." | "昨晚我女儿跟我说了一句话，我愣在原地。" |
| 主体 | "我们的课程体系包含三大模块..." | "我突然意识到，我一直在用'教'的方式跟她说话，但她需要的是'听'。" |
| 结尾 | "现在报名享受早鸟价..." | "我也经常有过这种'明明是为孩子好，却把孩子越推越远'的感觉，你不是一个人。" |
| 用户动作 | 问价→成交 | 点赞→收藏→关注→私信 |
机制：公域不是在跟一个人聊天，是在跟算法和人性注意力抢时间。先让人觉得你懂他，而不是先让人知道你多牛。

### 4. 抽象形容词→具体感受（定位语言）
【峰会·落地】"我是一个专业的/温暖的/真诚的IP"（错，用户只记住名字）→"用户刷到我，会觉得'他懂我经历的事'"（对，用户记住这种感觉）。
标签同理："我是做亲子教育的"太宽泛；"我理解每一个深夜被孩子作业逼疯的妈妈"立刻有人对号入座——**同一个标签下，藏着一千个不同的人。**

## 情绪配比（公域内容组合，不偏科）
【峰会·过河】正向（种草→A2了解+A5购买，"我也想这样"）50%；负向（避坑→A4决策，"幸好看到了"）20%；中性（疑问→A1认知+A3比较，"原来是这样"）30%。
注：A1-A5为富贵对5A认知阶段的引用；比例为经验建议非定律，用于检查偏科，不作硬指标。

## 让内容被转发：社交货币设计（转发的本质=替用户赚社交货币）【9月课·P26】
| 类型 | 用户心理 | 内容设计指令 |
|---|---|---|
| 提供谈资 | "我知道你不知道的事" | 反常识/新视角/行业内幕 |
| 助力表达 | "你说出了我想说的" | 金句/情绪共鸣/敢替群体说话 |
| 塑造形象 | "转它显得我有品" | 专业感/洞察感/审美在线 |
| 设置比较 | "我要表明立场" | 站队/投票/身份标签 |

## 三个高流量句式（9月课验证）
1. **价值观句式**【9月课·P21/25】："xxx应该xxx"替群体立价值观主张（"销售应该很勤奋"式）——动机的顶级加持，用户转发=表态。
2. **自测打分式标题**【9月课·P23】："好销售满足几条""爱妈妈的儿子答对几题"——自测即互动，统一流量密码。
3. **身份表达型内容**【9月课·P20】：让人宣告"我是什么人/我在做什么/应该做什么"的内容，比解决问题型内容更易裂变。

## 完成标准
- 交付改写稿时：新旧对照呈现（用户看得见变化）；附一句机制说明（为什么这样改）；用户拿去能直接发布。
- 禁止：只给原则不给改写；编造用户经历细节（宁可让用户填空：这里需要你的真实细节：____）；把"我懂你"做成一句空话（必须落到具体处境）。
