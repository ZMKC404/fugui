# AI 工作流：人性不变，情绪不变——知识库是护城河

核心原则【AI课】：AI 追风口/钻算法/堆内容三条旧路都是死路；AI 时代真正的护城河=**人性不变、情绪不变**，落点是"与我有关"的相关性+个性化知识库。**AI 能帮我们写故事，但不理解为什么——知识库越详实，产出越个性。**

## 人机分工（先分清，再用AI）【AI课·五要素】
人负责：**洞察**（看到别人看不到的）、**创造**（做产品）、**判断**、**审美**（好不好看，3.0阶段非标内容拼的就是它）、**行业经验**（如"萤石=专注之石"这种品类知识）。
AI负责：采集（评论区洞察情绪词）、扩展（种子词批量联想）、组装（按知识库批量生成）。
红线：让 AI 直接写内容而不喂知识库=产出同质化AI味；顺序必须是**人先定义用户状态→建知识库→AI生产→人审校**。

## 知识库五模块（含CORE ASSET）【AI课】
1. 产品信息（企业资料/规格/卖点事实）
2. 人群画像（卖给谁：状态/场景/身份）
3. 买点词库（5WTH买点词+行业归一词——把"水晶/手链/饰品"这类同义词归一）
4. 爆款案例库（对标笔记的结构/风格/人性弱点分析，目标100+篇）
5. **情绪词库=CORE ASSET**（AI 洞察评论区的高频情绪表达——这是各家差异化的核心资产）

搭建五步：汇总资料 → 整理成交付物 → 建立归一词标签体系 → 用优质正例+避坑反例充实 → 设定周更/月更。

## 用户状态倒推法（内容的起点，不是产品）【AI课·现场作业法】
**从状态倒推词，不从产品正推词。**
- 卖枕头：先写购买者状态（脖子疼、睡眠不足）→ 状态词即买点词 → 内容围绕状态说话。
- 水晶×考研党：考研党状态（脑雾、背了忘、总想玩手机）→ 种子词"提升专注力"→ 产品建议"萤石=专注之石"→ 内容绑定"ADHD学习工具"等低竞争词切入。
操作顺序：写用户状态（越具体越好：几点/在哪/身体感受/情绪）→ 状态词转搜索词 → 挑"竞争程度=低"的词做切入位。

## 搜商工程化：长尾关键词7步搜索路径【AI课】
1. 输入行业词 → 2. 筛选「评论最多」+「半年内」 → 3. 封面视觉筛选（哪些爆款长得好） → 4. 提炼高频词 → 5. 用高频词再搜索 → 6. 循环下钻到用户真正关心的点 → 7. 收获：长尾关键词库+对标笔记库+对标账号。
两阶段：基础筛选（精准过滤）+ 深度挖掘（核心提炼）。配套动作：AI提示词产出"关键词×搜索意图×内容类型×竞争程度"四维联想表+痛点词表（附情绪强度分级）。

## 内容组装公式（喂给AI之前先定配方）【AI课】
- 标题公式：人群词（30岁宝妈/学生党）+ 痛点词（脱发/焦虑）+ 效果词（逆袭/控痘）+ 时效词（7天/最新）。
- 笔记分布（A1-A5决策分层，主页科学配比）：A1入口吸引引流 → A2了解专业展示 → A2/A3验证案例展示 → A3比较服务说明 → A4决策疑问解答 → A5购买促成转化。
- 情绪组合公式：像调色一样先调情绪再生成内容——爱=快乐+信任、顺从=信任+恐惧、敬畏=恐惧+惊讶、懊悔=悲伤+厌恶、攻击性=愤怒+期待（源自情绪轮理论的商业应用）。
- 情绪叙事三幕法（宠物案例示范）：第一幕"我教你的第一课是爱和忠诚"→转折"第一口咬在你手上/最后一口咬在你心上"→终幕"我教你的最后一课是离别"。

## 去AI味操作清单（本skill自身也遵守）
1. 先有知识库再有生成——没喂料就让AI写=同质化。
2. 产出必须过人审：判断（对不对）、审美（好不好看）、经验（这行是不是这么回事）三关。
3. 情绪词库来自真实评论区（用户的原话），不是AI编的感受词。
4. 内容里保留具体场景与具体状态词（脖子疼>睡眠质量差）；具体性是人格，抽象性是AI味。
5. 平台策略：内容冷启动优先小红书（"1000个粉丝也能打爆流量"的逻辑，口播转述）。

## 完成标准
- 用户要"AI内容方案"时：交付=知识库缺什么清单+状态词/买点词候选（标注来源：用户原话/AI联想需验证）+生成流程+人审三关，而不是直接甩10条AI生成的文案。
- 引用配比/公式时保持"她的经验建议"口吻，不写成平台规则。
