# OKR 学习与压测成果（研究参考）

> 性质：本仓库的方法论经过 5 个行业迁移压测与 11 轮盲评对照测试的持续打磨，本页汇总学习过程中沉淀的可复用成果，**全部为研究性参考笔记**，不代表富贵官方观点。
> 更新：2026-11-06 · 对应 skill v2.1.5

## 一、五行业迁移压测结论（各行业压测全文见仓库研究说明）

| 行业 | 框架迁移度 | 关键发现（已固化进 skill） |
|---|---|---|
| B2B 软件销售 | 高 | 异议干预表/Find F 直接命中"联系人≠拍板人"机制 |
| 餐饮复购（线下） | 中高 | 地理半径与品类自然频次是框架缺失变量；"3秒决定"在线下失效（决策提前发生） |
| 高价知识付费 | 高（成交框架） | 客单价×信任阶梯、"低价课≠低承诺诊断层"、损失厌恶话术私聊可用公域禁用 |
| 跨境独立站 | 中高 | 买点词倒推跨语言**反向增强**（词源须本地化）；情绪资产公式缺"人"项→创始人IP化或降级两项半 |
| 家政（供给侧病） | 低-中 | **框架最大边界：需求侧变量全覆盖、供给侧零覆盖**——服务本身不稳时，营销只能兜伤害 |
| 宠物殡葬（污名化品类） | 低-中 | 平台行为假设整体翻转：转发=社交风险（"从死换到爱"改道）、关注语义污染、收藏=需求延期 |

→ 以上边界全部固化为 skill 内 **迁移守则 11 条**（references/strategy.md 末尾）。

## 三、过程方法论沉淀（对做 skill 的人有价值）

1. **先冻题后构建**：测试题与评分标准在写 skill 之前冻结，防"为分数优化"。
2. **对照测试+盲评+锚定摘录**：回归 T2/T5 曾出现评委甲乙对调，靠"逐字摘录首句"程序发现并校正——盲评副本必须剥离身份标题。
3. **失败是最好的迭代信号**：T6 情绪场景两轮失利换来"框架投放量纪律"（减框架不减方向），比任何一次成功都有价值。
4. **逐字重合扫描**：商用前用 n-gram 扫描 skill 与语料的重合（本仓库 `_work/scripts/verbatim_scan.py` 思路：≥18 字中文串检测），短语级金句带出处可引，整段照搬不可。
5. **知识三层**：逐字转录（档案）→ 方法卡（skill references）→ 路由（SKILL.md）；引用原文以精校引文库为准（canonical-quotes.md），不在库中不引不造。
