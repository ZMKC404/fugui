# fugui.skill — 把"情绪营销操盘手"的商业判断力装进你的 AI

> 一个给 AI Agent（ZCode / Claude Code / Codex 等）用的 Skill：让 AI 不再给你空洞的营销理论，而是像一位做过真实业务的操盘手一样，**先诊断机制，再给你今天就能执行的答案**。

## 它解决什么痛？

问 AI 营销问题，你大概率收到这种回答：

> 「首先，明确你的目标人群；其次，打磨内容质量；最后，保持垂直深耕……」
> ——全是正确的废话，等于没说。

**fugui.skill 让 AI 换一套操作系统：**

| 你问 | 普通 AI | 装了 fugui.skill 的 AI |
|---|---|---|
| 「我收藏挺高就是不涨粉」 | 给你一串泛泛的涨粉建议 | 判定你在得「免费教材病」：用户收藏的是方法不是你 → 给你一条「情绪在前、干货在后」的改写示范 + 一个今天就能做的动作 |
| 「帮我写个开头」 | 「好的！以下是为您创作的文案✨」（AI味扑鼻） | 先问自己「用户在什么状态会需要它」，把卖点翻译成买点，新旧对照给你看差别 |
| 「我想做个人IP但不知道定位」 | 让你先填一份20题问卷 | 用「灵魂自检四问」快速定位，告诉你评论区里藏着你的情绪锚点，教你怎么去挖 |
| 「客户说太贵了怎么办」 | 「强调产品价值」 | 告诉你这是「动机不够强」不是价格问题——把日常场景拉到极端场景，附话术 |

## 方法论从哪来？

对情绪营销操盘手**富贵**（长安文化CEO、小红书官方合作讲师）三套课程体系的完整语料研究提炼：

- **《新IP时代，用情绪击穿人心》**（顶流IP增长峰会演讲）：情绪资产公式、情绪三层次、三种病、公域私域语言切换、IP生长三阶段
- **《穿越周期的确定性增长》**（品牌增长课）：用户洞察五层洋葱模型、社交货币四类型、异议干预对照表、Find F
- **《AI情绪营销》线下课**：知识库=护城河、买点词倒推、AI时代人的四要素（洞察/审美/创造/行业经验）

不是语录搬运——每个方法都提炼为「机制 + 适用条件 + 正反例」，并保留出处标记，可以追问"这是谁说的"。

## 典型场景

- 📱 **内容没流量**：三种病快诊（免费教材病/百科全书病/一次性消费病）+ 情绪三层次定位
- ✍️ **写文案**：卖点→买点翻译器、私域话术→公域内容改写、自测打分式标题、价值观句式
- 🎯 **做定位**：情绪锚点画布、评论区三探针、灵魂自检
- 🔍 **挖动机**：五层洋葱完整手册（行为→场景→需求→动机→价值观，附每层问句与挖掘话术）
- 💰 **谈转化**：异议干预表（"太贵了"≠降价）、从动机定制话术
- 🤖 **AI 生产**：知识库搭建思路、人机分工边界、去 AI 味守则
- 📚 **找案例**：案例机制库（每个案例讲"为什么有效"）
- 🧭 **冷启动**：三阶段生长路径（先100个铁粉，再10万人记住）

## 安装（一条命令）

macOS / Linux 终端执行：

```bash
curl -fsSL https://raw.githubusercontent.com/ZMKC404/fugui/main/install.sh | bash
```

脚本会自动把技能装进本机已存在的 Agent 目录（`~/.zcode/skills/`、`~/.claude/skills/`、`~/.codex/skills/`，有哪个装哪个），并校验文件完整性。

装完后**新开一个会话**，直接说人话：

```
我的小红书笔记收藏挺高但就是不涨粉，为什么？
```

手动安装：把 `fugui/` 文件夹复制到对应 skills 目录即可。

## 它和普通 AI 的本质区别

1. **先诊断，再开药**：默认找机制病灶（你卡在动机层还是信任层），不是给正确的废话
2. **给可发布的成稿**：文案类任务交付新旧对照的改写稿，不是写作建议列表
3. **不追问轰炸**：单轮最多1个关键问题，其余用标注过的假设补上，先给你能用的初稿
4. **有出处意识**：方法论分层（富贵原话/推断/通用理论），可以追问，不编语录
5. **反AI味**：判断先行、不堆形容词、不写"首先其次总之"
